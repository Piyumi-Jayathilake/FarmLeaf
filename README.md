# 🛒 FarmLeaf – MERN Stack E-Commerce Platform

FarmLeaf is a full-stack online grocery platform designed for selling fresh vegetables and fruits.  
Built using the **MERN Stack**, it provides a seamless shopping experience with secure payments and an admin management dashboard.

---

## 🌐 Live Demo

- 🛍️ Customer Frontend: https://farmleaf-frontend.onrender.com  
- 🛠️ Admin Pannel: https://farmleaf-admin.onrender.com  

---

## 🚀 Features

### 👤 User Features
- User registration & login (JWT Authentication)
- Browse products by category
- Add to cart functionality
- Quantity management
- Secure checkout with Stripe
- Order history tracking

### 🛠️ Admin Features
- Add / Update / Delete products
- Upload product images (Cloudinary integration)
- Manage orders
- Monitor sales activity
- Inventory control

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- Context API / State Management
- Tailwind CSS
- Stripe Integration

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Cloudinary (Image Storage)
- Stripe API

### Deployment
- Render (Frontend & Backend Hosting)
- MongoDB Atlas (Database)
